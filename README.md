# 🚀 이클립스 깃(Git) & 브랜치(Branch) 사용 가이드

이 가이드는 초보자를 위해 이클립스에서 깃을 사용하는 핵심 과정을 정리한 문서입니다.

---

## 🌿 1. 브랜치(Branch) : 나만의 비밀 작업실 생성
원본(main)을 건드리기 전, 안전하게 작업할 복사본 공간을 만듭니다.
1. **생성:** 프로젝트 우클릭 → `Team` → `Switch To` → `New Branch...`
2. **이름:** `feature/기능이름` 형태로 입력 (예: `feature/login`)
3. **확인:** 프로젝트 이름 옆 괄호 `[브랜치명]`을 확인하세요.

---

## 📅 2. 작업 시작 (출근 도장: Pull)
작업 전, 항상 게시판의 최신 내용을 내 컴퓨터로 업데이트합니다.
* **방법:** 프로젝트 우클릭 → `Team` → **`Pull`**
* **팁:** 내가 쉬는 동안 동료가 올린 코드를 미리 가져와야 충돌이 적습니다.

---

## 🛠️ 3. 저장하기 (장바구니 & 메모: Commit)
파일을 수정했다면, 어떤 것을 올릴지 고르고 기록을 남깁니다.
1. **파일 선택:** `Git Staging` 창에서 수정한 파일을 `+` 버튼을 눌러 `Staged Changes`로 보냅니다.
2. **메모 작성:** `Commit Message` 칸에 작업 내용을 적습니다. (예: "로그인 버튼 색상 변경")
3. **내 컴퓨터 저장:** **`Commit`** 버튼을 클릭합니다.

---

## 📤 4. 서버 전송 (우체국 보내기: Push)
내 컴퓨터에 저장한 기록을 실제 인터넷 저장소(GitHub 등)로 보냅니다.
* **방법:** 프로젝트 우클릭 → `Team` → **`Push to Origin`**
* **참고:** 이제 다른 팀원들도 내가 만든 브랜치를 볼 수 있습니다.

---

## 🤝 5. 합치기 (작업실 내용을 원본에 넣기: Merge)
내 작업이 완벽하다면 원본(main)에 합치는 과정이 필요합니다.
1. **원본 이동:** `Team` → `Switch To` → `main` 선택
2. **합치기:** `Team` → **`Merge...`** 클릭 → 내가 작업한 브랜치 선택 → `Merge` 버튼 클릭
3. **최종 전송:** 합쳐진 `main` 브랜치를 다시 **`Push`** 합니다.

---

## 💡 무사고 깃(Git) 공식
> **[Branch 생성]** → **[Pull]** → **[코드 수정]** → **[Commit]** → **[Push]** → **[Merge]**

---

### ⚠️ 주의사항 (당황하지 마세요!)
* **Rejected (거절):** 누군가 먼저 새 글을 올린 상태입니다. 다시 **`Pull`**을 한 뒤 `Push` 하세요.
* **Conflict (충돌):** 같은 줄을 동시에 고쳤을 때 발생합니다. 파일에 **빨간색**이 뜨면 팀원에게 바로 도움을 요청하세요!
