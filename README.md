🚀 이클립스 깃(Git) & 브랜치(Branch) 사용 설명서
이 가이드는 게시판에 내 작업물을 올리고, 나만의 **비밀 작업실(Branch)**을 사용하는 방법을 설명합니다.

🌿 1. 브랜치(Branch)란? (나만의 비밀 작업실)
원본 코드(Main)를 직접 고치다가 실수하면 큰일 나겠죠? 그래서 원본을 복사한 나만의 작업 공간을 만드는 것입니다.

만들기: 프로젝트 우클릭 → Team → Switch To → New Branch

이름 짓기: 보통 feature/login처럼 내가 만들 기능 이름을 적습니다.

이동하기: Team → Switch To에서 내가 만든 브랜치 이름을 선택합니다. (이걸 '체크아웃'이라고 합니다.)

📅 2. 작업 시작 전 (출근 도장: Pull)
작업 전, 반드시 **내 작업실(Branch)**에 최신 내용을 가져와야 합니다.

방법: 프로젝트 우클릭 → Team → Pull

🛠️ 3. 작업 후 저장하기 (장바구니 & 메모: Commit)
파일을 수정했다면, 내 작업실에 기록을 남깁니다.

장바구니 담기: Git Staging 창에서 파일을 + 눌러 아래로 내립니다.

메모 작성: Commit Message에 작업 내용을 적습니다.

내 작업실 저장: Commit 버튼을 누릅니다.

📤 4. 서버에 올리기 (내 작업실 전송: Push)
내 컴퓨터에 있는 비밀 작업실을 인터넷 저장소로 보냅니다.

방법: 프로젝트 우클릭 → Team → Push to Origin

결과: 이제 인터넷 저장소에도 내 이름의 브랜치(작업실)가 생깁니다.

🤝 5. 합치기 (작업실 내용을 원본에 넣기: Merge)
내 작업실에서 만든 기능이 완벽하다면, 이제 원본(Main)과 합쳐야 합니다. (보통 팀장님이 하시거나 회의 후 진행합니다.)

원본으로 이동: Team → Switch To → main (또는 master) 선택

합치기: Team → Merge 클릭 → 내가 작업했던 브랜치 이름을 선택

최종 올리기: 합쳐진 원본 내용을 다시 Push 합니다.

💡 무사고 6단계 공식 (브랜치 버전)
[Branch 생성] (비밀 작업실) → [Pull] (최신화) → [작업] (코드 수정) → [Commit] (메모) → [Push] (작업실 전송) → [Merge] (원본에 합치기)

⚠️ 주의사항: 지금 내가 어디 있는지 확인하세요!
이클립스 프로젝트 이름 옆에 [my-branch-name] 처럼 내가 만든 브랜치 이름이 떠 있는지 항상 확인하세요. [main] 에서 직접 고치다가 실수하면 팀원 전체가 힘들어질 수 있으니까요!
