## 2. 📝 팀원 업무 리스트 (To-Do)

### A. SQL 매핑 점검 및 완성
> **작업 파일:** `userMapper.xml`

현재 테이블 컬럼명과 DTO 필드명이 대소문자나 형식이 다르므로 정확한 매핑이 필요합니다.
* **테이블 컬럼**: `PHONE`, `PW`, `NAME`, `EMAIL`, `BIRTH`, `GENDER`, `MEMBER_TYPE`
* **DTO 필드**: `phone`, `pw`, `name`, `email`, `birth`, `gender`, `memberType`
* **요청 사항**: 
    * `insert` 문에서 파라미터(`#{...}`) 매핑 확인
    * `select` 문에서 결과를 DTO에 담을 때 `resultMap` 등을 활용해 컬럼-필드 일치시킬 것

### B. 회원가입 로직 연동
> **작업 파일:** `MemberService.java`, `MemberController.java`

* **Service**: `registerMember` 메서드 호출 시 `MemberMapper`를 통해 DB에 값이 정상 입력되는지 확인
* **Controller**: 가입 성공 후 메인 페이지로 리다이렉트(`redirect:/`) 처리 점검

### C. 로그인 및 세션 처리
> **작업 파일:** `MemberController.java`, `header.jsp`

* **로그인 검증**: 컨트롤러 `login` 메서드에서 `MemberMapper.loginCheck` 호출하여 회원 존재 여부 확인
* **세션 저장**: 로그인 성공 시 `HttpSession`에 조회된 객체를 **`loginUser`**라는 이름으로 저장
* **화면 전환**: `header.jsp`에서 `sessionScope.loginUser` 존재 여부에 따라 `header_guest.jsp` 혹은 `header_user.jsp`가 출력되는 로직 확인

## 🔄 3. 전체 로직 흐름 요약

팀원들이 이해해야 할 핵심 데이터 흐름입니다.

### 👤 회원가입 흐름
`join.jsp` 입력  
➔ `MemberController` (POST)  
➔ `MemberService`  
➔ `MemberMapper`  
➔ `userMapper.xml` (**INSERT**)  
➔ 메인 페이지 이동

### 🔑 로그인 및 화면 표시
1.  **로그인**: `login.jsp` 입력 ➔ `MemberController` (POST) ➔ `MemberMapper` (**SELECT**) ➔ 세션(**loginUser**) 저장 ➔ 메인 이동
2.  **화면 상단**:
    * **세션 있음**: '...님 반갑습니다' & '로그아웃' 버튼 표시
    * **세션 없음**: '로그인/회원가입' 버튼 표시
